### Q1
#### Unit Testing
Definition:

Unit testing verifies the smallest testable part of an application, usually a single function or method, in isolation.

Example:
```java
public double calculateTotal(doublt price, int quantity) {
    return price * quantity;
}


assertEquals(200, calculateTotal(100, 2));
```

#### Functional Testing
Definition:

Functional testing verifies that the system behaves according the business requirements.

Example:
- Does the login feature accept valid credentials.
- Does the system reject invalid password.

#### Integration Testing
Definition:
Integration testing verifies that the multiple modules work correctly together.

Example:
- OrderService calls PaymentService.
- PaymentService update the database.
- The order status changes to "Paid".
#### Regression Testing
Definition:

Regression Testing ensures that recent code changes have not negatively affected existing functionality.

Example:
After modifying the payment logic, regression testing verifies:
- User can still log in.
- Order can still be created.
- Previous workflows still function correctly.
#### Smoke Testing
Definition:

Smoke testing is a preliminary test to verify that the basic functionalities of the System work after a new build.

Example:
- Can the application start.
- Can users log in.
- Does the homepage load.
#### Performance Testing
Definition:

Performance testing measures system responsiveness and stability under expected workload conditions.

Example:
- 1,000 user access the website simultaneously.
- Measure response time and CPU usage.
#### Stress Testing
Definition:

Stress testing evaluates system behavior under extreme or peak conditions beyond normal capacity

Example:
- 50,000 users attempt to purchase during a flash sale
#### A/B Testing
Definition:

A/B testing compares two versions of a product to determine which performs better base on user behavior.

Example:
- Version A: Red “Buy Now” button.
- Version B: Green “Buy Now” button.
Measure which version produces a higher conversion rate
#### End-to-End Testing
Definition:

End to end testing verifies the entire workflow from start to finish in production-like environment.

Example:
Simulate a complete user journey:
1. Register
2. Log in
3. Add item to cart
4. Place order
5. Make payment
6. Receive confirmation
#### User Acceptance Testing
Definition:

User Acceptance Testing is performed by end users or clients to verify the system meets business needs.

Example:
- Reports meet business requirements.
- Order workflows match company policies.
- The system satisfies contractual requirements.
