## Docker
Docker is a containerization platform that allows developers to package applications and their dependencies into lightweight, portable units called containers

## Core Docker concepts
#### Image
A Docker image is a read - only template used to create containers.

#### Container
A Container is a running instance of an image.
* Isolated process
* Shares host OS kernel
* Lightweight

#### Dockerfile
A Dockerfile defines how to build an image

#### Docker Registry
A Docker Registry stores and distributes Docker images.

#### Volumes
Volumes provide persistent storage for containers.

#### Networking
Docker provides container networking:
* Bridge network
* Host network
* Custom networks
Allows containers to communicate with each others

## Kubernetes
Kubernetes (K8s) is a container orchestration platform used to manage, scale, and deploy containerized application

Docker -> packages containers

Kubernetes -> manages containers at scale

### Kubernetes Core Architecture
Kubernetes follows a Master-Worker architecture.

#### Control Plane (Master Node)
Responsible for cluster management

Components:
* API server
* Scheduler
* Controller Manager
* etcd

#### Worker Node
Runs application containers

Components:
* kubelet
* kube-proxy
* Container runtime
### Core Kubernetes Concepts
#### Pod
A Pod is the smallest deployed unit in Kubernetes.
* Contains one or more containers
* Containers share:
  * Network
  * Store

#### Deployment
A Deployment manages Pods:
* Ensures desired number of replicas
* Supports rolling updates
* Self-healing

#### Service
A Service exposes Pods to network

#### ReplicaSet
Ensures specified number of pod replicas are running

#### Namespace
Logical reparation inside a cluster

#### ConfigMap and Secret
Used for configuration management.
ConfigMap -> non-sensitive config
Secret -> sensitive data
### Kubernetes Features
Auto scaling (HPA)
Self-healing
Rolling updates & rollbacks
Service discovery
Load balancing
Resource management
